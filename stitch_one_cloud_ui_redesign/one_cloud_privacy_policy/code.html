Zero Binary Custody Guarantee

One Cloud does not store, inspect, sell, or monetize the binary byte content of your files. All files are encrypted using standard MTProto protocols and relayed directly to your own Telegram account’s "Saved Messages" channel.

01

Introduction & Architecture Overview

Welcome to One Cloud (“we”, “us”, or “our”). One Cloud operates as a specialized client orchestration layer designed to give users a full-featured desktop and web drive interface powered entirely by Telegram’s cloud storage infrastructure.

By accessing or using our services at onecloud.app or our desktop applications, you acknowledge and accept the data handling practices outlined in this Privacy Policy. This policy explains how we collect and separate identity credentials, organizational metadata indexes, and MTProto media streams.

02

Information We Collect

To provide instantaneous file navigation, search filtering, and virtual hierarchical folders, One Cloud bifurcates user data into strict operational categories:

badge Account & Auth
  • Primary verified email address
  • Firebase Authentication User Identifier (UID)
  • Telegram Telegram-ID (numeric pointer)
  • Hashed session tokens (stored locally)
folder_data Virtual Index Metadata
  • User-defined file and directory names
  • MIME type extensions & byte sizes
  • Parent/child folder relational IDs
  • Telegram message ID mapping references
  • Favorites, star markers, and custom tags

Diagnostic Telemetry: We collect non-identifiable runtime crash reports and network latency metrics to optimize chunk transfer reliability. Telemetry never contains file names, directory structures, or Telegram authentication hashes.

03

Telegram Storage & Data Custody

One Cloud acts exclusively as a visual operating system on top of your own personal Telegram cloud space. When you upload any asset:

MTProto Direct Pipe Pipeline Zero intermediary caching
1
Local Browser

Chunking and hash digest verification occurs directly on your client hardware.

2
Telegram MTProto

Payloads stream straight into Telegram's servers via authorized bot worker pipes.

3
Saved Messages

The native file entity exists permanently inside your personal chat history.

Because One Cloud does not possess the physical hard drive infrastructure where your binary payload rests, Telegram FZ-LLC remains the legal and technical custodian of the underlying encrypted file chunks. You can read Telegram’s official privacy terms directly on telegram.org.

04

Firebase Authentication & Metadata Indexing

Without metadata caching, a drive system would be forced to fetch and parse tens of thousands of messages from your Telegram chat timeline every time you open a folder. To achieve sub-second speeds:

  • Firestore Clustered Trees: Directory structures, nested hierarchies, file labels, and permissions are indexed in secure Google Firebase / Google Cloud Firestore clusters.
  • Pointer Encryption: Pointers to Telegram message IDs are isolated so only your authenticated Firebase UID holds read and write permissions under strict Cloud Security Rules.
  • Local IndexedDB Sync: Frequently referenced folder paths are cached locally inside your browser storage for instant navigation.

06

Third-Party Disclosures & Non-Monetization

One Cloud is founded on a privacy-respecting business model. We do not sell user data, license indexing trends, or construct behavioral advertising profiles.

Sub-processors we work with:
Google Firebase / Cloud Infrastructure User authentication & encrypted index persistence
Telegram FZ-LLC Direct file payload transfer and encrypted data storage
07

Data Retention & Permanent Deletion

When you interact with the deletion lifecycle in One Cloud:

1. Move to Trash

The metadata record is flagged as soft-deleted. The underlying Telegram message remains untouched in your Saved Messages history.

2. Empty Trash / Permanent Purge

The metadata document is permanently and irreversibly destroyed from our Firestore clusters. If enabled in your settings, our bot worker also sends an MTProto deletion command to remove the message from your Saved Messages.

08

User Rights & Data Portability

Regardless of geographic residence, all One Cloud users retain comprehensive control over their personal records:

file_download Metadata Export Export your entire folder hierarchy index as JSON or CSV anytime.
link_off Unlink Bot Session Revoke bot access directly in Telegram via BotFather in 1 click.
delete_forever Complete Account Wipe Purge account credentials and cloud metadata records instantly.
09

Security & Payload Isolation

All traffic between your client device and our metadata services utilizes strictly enforced TLS 1.3 encryption. Internal datastores utilize Google Cloud AES-256 server-side encryption at rest. We continuously subject our codebase to automated static security analyses to prevent token exfiltration.
