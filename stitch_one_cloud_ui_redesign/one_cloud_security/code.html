A. Authentication & Session Handling

One Cloud utilizes Firebase Authentication for secure identity management and JSON Web Token (JWT) exchange. Short-lived session claims are validated against strict security rules on every metadata read or write.

  • check Zero Phone Passwords Stored: One Cloud never asks for or stores your master Telegram phone password.
  • check Scoped Bot API Tokens: Bot tokens operate with restricted privileges limited strictly to document dispatching.
  • check Isolated Ephemeral Keys: Temporary credentials expire automatically without leaving persistence footprints.
SPEC // 02 MTProto v2.0 / TLS 1.3
sync_alt

B. MTProto Transmission & Data in Transit

All data streaming between the client browser and Telegram Data Centers relies on MTProto v2.0 over TLS 1.3 tunnels, guarding against passive network eavesdropping and man-in-the-middle attacks.

  • check 2,048-bit RSA Handshake: Cryptographic Diffie-Hellman key exchange directly negotiated with Telegram DCs.
  • check SHA-256 Chunk Verification: Chunked binary streams validate block integrity sequentially on client download.
  • check AES-256-IGE Ciphering: Telegram's native data channel cipher ensures zero packet inspection in transit.
SPEC // 03 Hard Tenant Silos
folder_supervised

C. Access Control & Tenant Isolation

Multi-tenancy isolation is enforced at the database layer. No user can scan, enumerate, or query metadata nodes belonging to another user.

  • check No Cross-Account Indexing: No centralized search indexing aggregates files across independent user accounts.
  • check Row-Level Rule Enforcements: Firestore security rules reject requests whose token UID does not match node owner.
  • check Strict Zero Shared Drive Leaks: Personal storage buckets remain isolated to your Telegram channel destination.
SPEC // 04 Shared Responsibility
verified_user

D. User Responsibilities & Hardening

Security in a zero-custody framework is a collaborative contract. Because we do not store your binaries, safeguarding account credentials is vital.

  • priority_high Telegram Two-Step Verification (2FA): Always configure a secondary cloud password inside your Telegram app settings.
  • check Active Session Auditing: Regularly review Telegram → Settings → Devices to audit active bot sessions.
  • check Local Browser Cleanliness: Keep web extensions audited, as client-side tokens reside within your secure browser sandbox.
